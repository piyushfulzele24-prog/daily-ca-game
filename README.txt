DAILY CA CHALLENGE - UPLOAD GUIDE

Files in this package (all go in the MAIN page of your GitHub repo):
  index.html            the game
  questions/latest.json 10 SAMPLE questions so you can test (replace daily)
  daily-prompt.txt      the prompt to use each day

ONE-TIME SETUP
1. github.com > New repository > name it daily-ca-game > Public > Create.
2. Unzip this package. Open the unzipped folder and select everything INSIDE it.
3. In the repo click Add file > Upload files, drag the selected items in, click Commit changes.
4. Repo Settings > Pages > Source: Deploy from a branch > Branch: main, folder / (root) > Save.
5. After 1-2 minutes your game is live at the address Pages shows.

DAILY ROUTINE
1. Use daily-prompt.txt in Claude (web search on) and download latest.json.
2. Repo > questions folder > Add file > Upload files > drop latest.json > Commit.
